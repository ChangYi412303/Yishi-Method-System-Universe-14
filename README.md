# Yishi-Method-System-Universe-14

# 沒有什麼是「本來就該如此」

## 從拆解理所當然，到重新取得判斷與選擇的主權

**作者：張枍／來者何枍**  
**整理日期：2026年11月11日09點41分**

---

## 一、先拆掉「本來就該如此」這個預設

我想提出一個觀點：

**沒有任何事物、制度、觀念或價值，是在它出現以前，就已經注定應該存在的。**

沒有 AI 以前，AI 是本來就應該存在的嗎？

沒有智慧型手機以前，智慧型手機是人類本來就應該擁有的東西嗎？

沒有清朝以前，民國就已經注定要出現嗎？

沒有儒家、法家以前，今天我們熟悉的倫理、道德、法律與社會規範，又是從哪裡來的？

答案很清楚：它們都是在特定的歷史條件下，經過人類的思考、選擇、衝突、合作、權力運作與社會演變，逐步形成的。

今天被稱為理所當然的事物，往往只是因為它存在得夠久、被使用得夠廣泛、被教育得夠深入，最後讓人忘記：它其實曾經不存在，也曾經有其他可能。

因此，我真正想拆解的不是某一條規定、某一種道德或某一套制度。

而是人們經常不經思考，就把「現在存在的事物」，直接等同於「本來就應該如此」。

**存在，不等於天生正當；習慣，不等於真理；被多數人接受，也不代表永遠不能質疑。**

## 二、所有制度都是人類形成的，但不代表所有制度都毫無價值

國家、法律、教育、家庭倫理、企業制度與社會規範，都不是自然界原本就存在的完整體系。

它們是人類為了處理共同生活中的問題，逐步建立起來的安排。

其中有合作，有治理需求，有安全考量，有利益分配，也有權力競爭、恐懼、自私與控制。

我不認為所有制度都只是某些人為了私欲而創造的工具。那樣的解釋太簡單，也無法說明人類為什麼會建立互助、公共安全與權利保障制度。

但我同樣不接受另一種說法：只要制度存在，就代表它合理；只要權威制定，就代表人民理應服從；只要有人說「本來就是這樣」，就不需要再追問原因。

制度可以有存在的理由，也可能在發展過程中偏離原本目的。

法律可以維持秩序，但法律的制定、執行與修正，仍然必須接受檢驗。

所以，我可以為了共同生活與社會治理，接受合理、必要，而且能隨著時代與社會發展調整的法規。

但這不代表我必須在思想上，將每一項制度都視為天然正確。

**遵守現行規則，不等於放棄檢驗規則；接受治理需要，不等於無條件認同治理者。**

## 三、「本來就不存在」與佛教空性：相近的提問，不必急著畫上等號

我曾經反問：

如果一切事物都不是原本就存在，那麼所謂的「本來就應該如此」，究竟有什麼不可質疑的根據？

這讓我聯想到佛教所談的「空」。

但這裡需要把概念說清楚。

佛教的空性，不宜簡化成「所有東西都不存在」。更精確地說，它所探討的是：事物並沒有一個完全獨立、永恆不變、不依賴任何條件的固定自性。

事物會因條件、關係與因緣而形成，也會隨條件改變而變化。

因此，我的觀點與空性可以形成對話，但不應直接宣稱兩者完全相同。

我想追問的是：

既然制度、觀念與價值都有其形成條件，為什麼我們要把某個時代的產物，當成永遠不能改變的真理？

既然規則是人制定的，為什麼制定規則的人、執行規則的人，以及受到規則影響的人，不能共同檢驗它是否合理？

這不是要否定所有存在，而是要拒絕把「已經存在」偷換成「永遠正當」。

## 四、接受，不等於接納；遵守，不等於認同

這是我認為整個觀點最具有實際用途的地方。

人生活在社會裡，不可能完全脫離制度。

我們需要法律處理衝突，需要交通規則維持安全，需要公共制度分配資源，也需要共同約定，讓不同的人能夠生活在同一個社會。

但是，接受現實上的治理需要，不代表必須認同每一項規定的設計；遵守現行法律，也不代表不能依法提出異議、要求說明或尋求修正。

例如：

- 法律存在，不代表法律永遠不需要檢討。
- 公務員依法執行職務，不代表執行方式不需要接受監督。
- 家庭有其倫理關係，不代表長輩的每一個要求都合理。
- 企業有管理制度，不代表管理者可以把不合理的要求包裝成公司文化。
- 心理學有專業知識，不代表任何理論、診斷或心理標準都不容質疑。

真正需要區分的是：

**我知道這個制度目前存在，也知道它對現實生活具有影響；但我仍然保有判斷它是否合理、是否需要改變的權利。**

這不是拒絕現實，而是不把現實當成唯一答案。

## 五、這個觀點也能用來檢驗心理學，而不是直接否定所有心理學

我也想把這個問題帶進心理學。

所謂心理學的理論、分類、測量工具與診斷標準，同樣是在特定歷史、文化、研究方法與社會條件下逐步發展出來的。

它們不是從人類誕生以前，就已經完整存在的自然法則。

因此，任何心理學理論都應該接受檢驗：

1. 它研究的是哪些人？研究樣本是否具有代表性？
2. 它所使用的文化背景，能不能直接套用到其他社會？
3. 它描述的是普遍的人類現象，還是特定時代與環境下的行為模式？
4. 它的分類與測量，是否真的能幫助理解當事人？
5. 它提出的方法，能否在真實生活中產生可觀察、可檢驗的效果？
6. 當理論與當事人的實際經驗不一致時，是否允許重新檢查理論？

這些問題不只適用於西方心理學，也適用於東方思想、傳統倫理，以及任何自稱具有普遍性的知識體系。

我不需要因為某套理論來自西方，就先承認它具有正統地位；也不需要因為它來自東方，就認為它必然更接近真理。

**知識的價值，不應由它的出身決定，而應由它的證據、解釋能力、適用條件與實際效果來檢驗。**

因此，我要挑戰的不是心理學存在的價值，而是任何理論把自己放在不可質疑的位置。

如果某種心理標準只會要求當事人適應環境，卻不願意檢查環境本身是否合理，那麼我們就應該追問：問題究竟出在個人、環境，還是兩者之間的互動？

不能只因為一個人不符合某種標準，就直接把他定義成問題本身。

同樣地，也不能反過來，把所有心理困擾都歸咎於社會制度。人的身體、經驗、關係與環境都可能共同影響心理狀態。

理解問題，需要拆解條件，而不是急著替人貼上標籤。

## 六、把「本來就該如此」轉化成可以使用的思考工具

這個觀點不是要人否定一切，也不是要人為了反抗而反抗。

它真正的用途，是在我們遇到一項規定、一種要求、一個價值判斷，或一段被視為理所當然的關係時，先停下來問：

**第一，這件事是什麼時候形成的？**

它是自然條件、歷史發展、社會約定，還是某些人的選擇？

**第二，它原本要解決什麼問題？**

現在的做法，還有沒有達成當初的目的？

**第三，誰從這套安排中受益？誰承擔成本？**

利益與責任是否合理分配？有沒有被忽略的人？

**第四，它是否仍然適用現在的環境？**

過去合理的做法，不代表今天仍然合理。

**第五，有沒有其他可行方式？**

如果存在更有效、更公平、成本更低的選擇，就應該有重新檢討的空間。

這五個問題，可以用在家庭、職場、人際關係、法律制度、公共政策，也可以用來檢查自己長期相信的觀念。

它不是要求每個人都推翻現有生活，而是讓人不必因為一句「本來就是這樣」，就放棄自己的判斷。

## 七、真正的轉變，是從不再把習慣當成答案開始

很多人不是沒有思考能力，而是從小到大，太多事情都被包裝成不需要思考的答案。

父母說應該如此，學校說應該如此，主管說應該如此，社會說應該如此。

久而久之，人可能連自己是否認同，都還沒弄清楚，就先照著做了。

但一件事情被重複一百次，不代表它就變成真理。

一套制度延續一百年，也不代表它永遠不需要改變。

一個人長期相信某種價值，更不代表他不能重新檢查自己的信念。

我想做的，是把這個思考起點重新交還給每一個人：

你可以理解制度，但不必神化制度。

你可以尊重專業，但不必放棄查證。

你可以遵守規則，但不必放棄依法提出質疑的權利。

你可以接受生活中的限制，但不必把限制誤認成自己的天命。

**沒有什麼只是因為「本來就如此」，就自動取得了永遠正確的資格。**

看清它如何形成，理解它為何存在，檢查它是否合理，再決定自己如何面對。

這才是判斷力。

這才是把主權拿回來的起點。

---

## 結語

我不主張為了否定而否定，也不主張把所有制度、道德、法律或心理學都當成敵人。

我只反對一件事：

**有人把人類自己建立的規則，說成不容質疑的天經地義；再用「本來就該如此」，要求其他人放棄思考。**

制度是人建立的，就應該接受人的檢驗。

知識是人發展的，就應該接受證據的檢驗。

觀念是人在生活中形成的，就應該允許人重新思考。

生活不是為了服從某個永遠不變的答案。

我們可以理解現實、使用制度、尊重專業，同時保留重新判斷與選擇的能力。

**沒有什麼是本來就該如此。存在可以被理解，合理性必須被檢驗，而選擇權不應被一句「本來就是這樣」奪走。**
